# Projection Model

## Purpose

Symmetry read models must be reconstructible from chain events and evidence manifests.

## Primary projections

- enterprise roots
- service installations
- evidence manifests
- audit timelines
- signer registry

## Initial event dependencies

- `EnterpriseRootDeployed`
- `EnterpriseOnboarded`
- `CorporateIdentityCreated`
- `EnterpriseServiceConfigured`
- `EvidenceAnchored`
- `EvidenceManifestUpdated`
- `AuditRecordCreated`

## Initial read models

- `enterprise_root_projection`
- `service_installation_projection`
- `evidence_projection`
- `audit_timeline_projection`
