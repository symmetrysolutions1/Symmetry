# Pre-Service Readiness Checklist

Before building a business service such as `VotoID`, Symmetry should already have:

1. root-per-company deployment flow
2. chain abstraction with initial target config
3. manifest-aware evidence anchoring
4. audit model with service and action context
5. service installation model
6. base event/projection plan

Status in current repo:

- root-per-company deployment flow: present
- chain abstraction: present
- manifest-aware evidence: present
- audit context model: present
- service installation model: present
- projection model: present
