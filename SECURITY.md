# Security Policy

Symmetry Enterprises is under active security hardening and has not completed an independent external audit.

Do not open public issues containing vulnerabilities, credentials, private keys, enterprise evidence, or customer data. Report security matters privately to `symmetrysolution1@gmail.com`.

Production deployments require:

- a passing production readiness gate
- contract-source verification
- independently controlled multisigs
- rotated deployment credentials
- evidence persistence health across IPFS, Filecoin, and Arweave
- an external smart-contract audit before handling material enterprise operations
